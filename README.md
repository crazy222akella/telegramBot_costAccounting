# telegramBot_costAccounting

## Описание проекта
Проект представляет собой Telegram-бота, предназначенного для учёта личных финансов пользователя.  
Основная задача — предоставить простой инструмент для записи и просмотра трат прямо в чате.

---

## Функционал

### Добавление расходов
Пользователь может отправить сумму (с описанием или без), после чего бот:
- сохраняет расход
- привязывает его к пользователю

---

### Хранение данных
Все траты сохраняются в базе данных, что позволяет:
- не терять данные между перезапусками
- вести историю расходов

---

### Просмотр расходов
По запросу бот выводит:
- список всех трат
- суммарную информацию (например, общая сумма)

---

## Принцип работы
1. Пользователь отправляет сообщение боту
2. Бот обрабатывает данные
3. Сохраняет информацию в базе данных
4. Возвращает результат пользователю

---

## Используемые технологии
- Python
- Telegram Bot API
- База данных (укажи свою: SQLite / PostgreSQL и т.д.)
