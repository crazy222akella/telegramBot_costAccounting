# telegramBot_costAccounting
Проект представляет собой Telegram-бота, предназначенного для учёта личных финансов пользователя. Основная задача — дать простой инструмент для записи и просмотра своих трат прямо в чате.


Бот реализует базовые, но полезные возможности:
    Добавление расходов. Пользователь может отправить сумму (с описанием или без), после чего бот:

        сохраняет расход
        привязывает его к пользователю

    Все траты сохраняются в базе данных, что позволяет:

        не терять данные между перезапусками
        вести историю расходов
    Просмотр расходов. По запросу бот выводит:

        список всех трат
        или суммарную информацию (например, общая сумма)
